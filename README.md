# study

学習アプリをまとめたリポジトリです。各フォルダが1つのアプリです。

GitHub Pages: https://kouheim1979.github.io/study/

| フォルダ | タイトル | 分野 |
|---|---|---|
| [toeic](toeic/) | TOEIC形式 英語トレーナー | 英語 |
| [pattern-pocket](pattern-pocket/) | Pattern Pocket（キッズ版あり） | 英語 |
| [soundbeat](soundbeat/) | SoundBeat | 英語 |
| [eigo-quest](eigo-quest/) | えいごヒマつぶしクエスト | 英語 |
| [Turn-method](Turn-method/) | えいごヒマつぶしクエスト（Turn-method版） | 英語 |
| [zenken-moshi-lab](zenken-moshi-lab/) | 成績ラボ（単元分析・全県模試） | その他 |

そのほか、`eigo-ai`（えいごヒマつぶしクエスト用のVercel AIバックエンド）と `kouhei-ai`（相談室）が同居しています。

`Turn-method` は元のリポジトリからコピーしたものです（元のリポジトリは残しています）。ことば・地理などのクイズ系は [games](https://github.com/kouheim1979/games) にあります。

このリポジトリは旧名 `toeic` です。以前ルートにあったTOEIC形式 英語トレーナーは `toeic/` フォルダへ移しました。
