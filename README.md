# study

学習アプリをまとめたリポジトリです。各フォルダが1つのアプリです。

GitHub Pages: https://kouheim1979.github.io/study/

| フォルダ | タイトル | 分野 |
|---|---|---|
| [rems-reader](rems-reader/) | R.E.M.S. Reader（QQEnglish公式PDF教材ビューア） | 英語 |
| [shadowing-studio](shadowing-studio/) | Shadowing Studio（6ステップの英語シャドーイング・録音と添削の受け渡し） | 英語 |
| [echo-lines](echo-lines/) | Echo Lines（テキストから自動でシャドーイング教材を作成・端末の読み上げを使用） | 英語 |
| [toeic](toeic/) | TOEIC形式 英語トレーナー | 英語 |
| [pattern-pocket](pattern-pocket/) | Pattern Pocket（キッズ版あり） | 英語 |
| [soundbeat](soundbeat/) | SoundBeat | 英語 |
| [eigo-quest](eigo-quest/) | えいごヒマつぶしクエスト | 英語 |
| [Turn-method](Turn-method/) | ターンメソッド（英語発話トレーニング） | 英語 |
| [eiken3-mensetsu](eiken3-mensetsu/) | 英検3級 面接ルーム（二次試験の面接練習） | 英語 |

そのほか、英語練習用のAIバックエンドと、ローカルAI相談室のコードが同居しています。

`Turn-method` は元のリポジトリの4月18日版（ターンメソッド本体）をコピーし、崩れていたCSSを修正したものです（元のリポジトリは残しています）。ことば・地理などのクイズ系は [games](https://github.com/kouheim1979/games) にあります。

このリポジトリは旧名 `toeic` です。以前ルートにあったTOEIC形式 英語トレーナーは `toeic/` フォルダへ移しました。
