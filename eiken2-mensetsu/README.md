# 英検2級 INTERVIEW QUEST

中学生にも取り組みやすい、英検2級の二次試験を模した **非公式のオリジナル面接練習アプリ**。

- 画面のバーチャル試験官が、音声読み上げと連動して口を動かします。**実際の動画／リアルタイム生成AIの会話ではありません**。
- 本番チャレンジ（字幕は原則非表示）とやさしい練習（字幕・ヒントつき）を切り替えられます。
- 入室 → 20秒黙読 → 音読 → No.1（文章）→ 20秒準備 → No.2（3コマ）→ カードを裏返す → No.3, No.4（意見）→ 退室。2026年11月時点の英検2級二次試験公式形式を参照しました。
- 4セットの問題はすべてオリジナル。実際の過去問・公式サンプルの転載ではありません。
- 英語音声はブラウザの `speechSynthesis`。音声入力は対応ブラウザの `SpeechRecognition` を使用します。端末やブラウザによっては使用できないので、手入力でも使えます。
- 回答メモをお手本と比較できますが、**AI採点・発音の判定や合否判定はありません**。
- 学習回数と連続日数をその端末の `localStorage` に保存します。回答メモはページを閉じたら消え、アプリのサーバーには送信しません。端末の音声認識機能が使う外部サービスの処理には端末・ブラウザの仕様が適用されます。

## A4カード印刷

ホーム画面の「4枚まとめて印刷」または「選択中の1枚だけ」ボタンからブラウザの印刷画面を開けます。A4縦・倍率100％・余白はブラウザ既定で印刷してください。問題カードは英語のパッセージ、3コマの絵、導入文のみ。質問や模範解答は印刷されません。外部のPDF作成サービスを経由しません。

## 音声認識の改善（2026年11月14日）

- 「🎤 直接音声認識」：対応ブラウザのWeb Speech APIを使用。認識が応答しない場合は15秒後に原因を表示します。iPhoneでは端末によって不安定なことがあります。
- 「🎙️ 録音してAI変換」：マイクの利用許可を求め、手動で録音を止めるか上限時間に達すると音声を文字起こしします。録音データを利用者がボタンを押した時だけVercel上の既存AIバックエンド（`eigo-quest-ai-kouheim-3013.vercel.app`）へ送信し、そのサーバーからAI Gatewayへ転送します。利用できるかどうかはバックエンドの稼働状況や利用枠に依存します。
- 認識済みのテキストは回答欄に追加されます。外部AIへの送信が不要な場合はキーボードのマイク・手入力を使用できます。
- 動画風の試験官と英語音声読み上げはこれまで通り端末のブラウザで実行します。
- **個人情報・録音内容を送信したくない場合はAI変換ボタンを押さないでください。** 認識の精度は保証されません。端末に保存した練習回数以外の音声ファイルをアプリが永続保存することはありません。
