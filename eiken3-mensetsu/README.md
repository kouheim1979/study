# 英検3級 面接ルーム

英検3級の二次試験（面接）を、入室から退室まで本番の順番で通して練習するアプリです。

- あいさつ → 20秒の黙読 → 音読 → No.1（パッセージ）→ No.2・3（イラスト）→ カードを裏返す → No.4・5（自分のこと）→ 退室
- 面接委員の質問は英語で読み上げます（ブラウザの音声合成）。本番モードでは質問の文字を表示しません。
- 「Could you say that again?」で聞き直しの練習ができます。
- 答えは声に出してから入力します。キーボードのマイクで音声入力すると本番に近くなります。
- 問題カードは5枚（A〜E）。パッセージとイラストは練習用のオリジナルで、実際の過去問ではありません。

## 採点

- Claude のアプリ内（アーティファクト）で開いたときだけ、No.1〜5 を Claude が採点します。
- GitHub Pages で開いた場合は自動採点が使えないため、お手本と比べて自分で点数をつけます。
- 音読とアティチュード（態度）はどちらの場合も自己採点です。合計33点満点で、合格目安の17点と比べて表示します。

## 画面更新（2026年11月）

- 学生にも見やすいトップ画面、動くバーチャル面接官を追加しました。
- 面接官の口と音声読み上げが連動します。実写映像やリアルタイムAIとの会話ではありません。
- 音声入力対応ブラウザでは、回答欄の「🎤 音声入力」ボタンから回答を記録できます。非対応なら手入力を使用します。
- 既存の5枚の問題カードと3級の出題順は維持しています。

## A4カード印刷

ホーム画面の「5枚まとめて印刷」または「選んだ1枚だけ印刷」ボタンから印刷できます。A4縦・倍率100％で印刷し、枠に沿って切り取って使ってください。問題カードには文章とイラストだけが載り、問題の解答は載りません。

## 音声認識の改善（2026年11月14日）

- 「🎤 直接音声認識」：対応ブラウザのWeb Speech APIを使用。認識が応答しない場合は15秒後に原因を表示します。iPhoneでは端末によって不安定なことがあります。
- 「🎙️ 録音してAI変換」：マイクの利用許可を求め、手動で録音を止めるか上限時間に達すると音声を文字起こしします。録音データを利用者がボタンを押した時だけVercel上の既存AIバックエンド（`eigo-quest-ai-kouheim-3013.vercel.app`）へ送信し、そのサーバーからAI Gatewayへ転送します。利用できるかどうかはバックエンドの稼働状況や利用枠に依存します。
- 認識済みのテキストは回答欄に追加されます。外部AIへの送信が不要な場合はキーボードのマイク・手入力を使用できます。
- 動画風の試験官と英語音声読み上げはこれまで通り端末のブラウザで実行します。
- **個人情報・録音内容を送信したくない場合はAI変換ボタンを押さないでください。** 認識の精度は保証されません。端末に保存した練習回数以外の音声ファイルをアプリが永続保存することはありません。
