自分専用サーバーの設定

Cloudflare（無料）に小さな中継プログラムを置くと、全教材がこの画面の中でページ単位で表示・保存できます。所要5分・最初の1回だけ。

1Cloudflareに無料登録

Cloudflareを開く ↗

メールアドレスとパスワードで登録します（クレジットカード不要）。登録済みならログインするだけです。

2GitHubから取り込む（貼り付け不要）

  1. ホーム画面の Create app（または メニュー ≡ → Workers & Pages → Create）
  2. Import a repository（Gitリポジトリを取り込む）を選ぶ
  3. GitHub を連携（初回だけGitHubのログイン・許可画面が出ます）
  4. リポジトリ kouheim1979/study を選ぶ
  5. 設定画面で次のとおり入力して Deploy：
    • Project name：rems-proxy
    • Build command：空欄のまま
    • Deploy command：npx wrangler deploy（最初から入っていればそのまま）
    • Root directory / Path（「Advanced settings」内にあることも）：rems-reader/worker

1行だけの欄なので、長押し→ペーストで入ります。画面の名前は時期によって少し違うことがあります。

3（GitHub連携できない場合だけ）手で貼り付ける

開く

Create app → Start with Hello World! → 名前 rems-proxy で Deploy → Edit code で中身を全部消して下のプログラムを貼り付け → Deploy。iPhoneでは貼り付けにくいので、パソコンがあればそちらがおすすめです。

読み込み中…

このプログラムはQQEnglishのR.E.M.S.教材PDFだけを取得し、あなたのリーダー（kouheim1979.github.io）にだけ渡します。他の用途には使えません。

4URLを貼って完了

デプロイ後に表示される https://rems-proxy.〇〇〇.workers.dev をコピーして、ここに貼り付けてください。
