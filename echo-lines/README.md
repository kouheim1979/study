# Echo Lines（エコーラインズ）

英文テキストをアップロードまたは貼り付けるだけで、シャドーイングの練習教材を自動で作るWebアプリです。
読み上げには端末に入っている音声合成（iPhoneでは Siri などの声）を使うので、音声ファイルは必要ありません。
ログイン・APIキー・サーバーは不要です。入力したテキスト・録音・学習記録はこの端末の中だけに保存されます。

- 公開URL: https://kouheim1979.github.io/study/echo-lines/
- iPhone の Safari を優先して設計しています。PC の Chrome / Edge / Safari でも使えます。

## 自動で作られるもの

テキストを入れると、次のものを端末内で自動生成します（外部への送信はありません）。

| 項目 | 内容 |
|---|---|
| 文・チャンク | 文に分けたうえで、カンマや接続詞（and, because, to など）の位置で4〜8語程度の意味のかたまりに分割（長さは選択可） |
| キーワード | よく使う語を除いて、長めの語・くり返し出る語・発音に注意が必要な語を最大10個選ぶ（人名・地名は除外） |
| 音の変化の解説 | つづりから推定した目安。連結（check in）、t の弾音化（get a、water）、語末の破裂音の脱落（last week）、同じ子音の連続（want to）、you との同化（did you→「ジュ」）、決まった短縮（want to→wanna、going to→gonna など）、弱く読まれる機能語、黙字（listen の t、walk の l など） |
| 穴うめ問題 | キーワードを空欄にした3択問題（最大5問） |
| レベル | 文の長さと長い単語の割合から A1〜C1 を推定 |
| 和訳 | 自動翻訳はしません。和訳を1文ずつ改行して貼ると各文に対応づけます。未入力の文には、翻訳サイトを開くリンク（押したときだけ通信）を表示します |

字幕ファイル（.srt / .vtt）の番号・時刻と、「Tom:」のような話者名は自動で取り除きます。

## 練習の流れ（6ステップ）

1. **聞く**：英文を見ずに読み上げを通して聞き、聞き取れた割合を自己評価
2. **単語**：キーワードを「単語だけ／ゆっくり／文の中で」の3通りで聞く。意味をメモでき、辞書サイトへのリンクもあり
3. **意味**：チャンクごとに読み上げ、解説を見ながら意味をとる（チャンクごとの意味メモも可）
4. **リピート**：1チャンク読み上げたら、ポーズの間に声に出す（ポーズの長さ・回数を選択、録音も可）
5. **シャドー**：読み上げに合わせて声に出しながら録音し、チャンクごとに「お手本（読み上げ）→自分の声」で聞き比べ
6. **確認**：文ごとの和訳、穴うめ問題、最初の自己評価との比較、完了の記録

どのステップにも上部の番号から戻れます。共通の操作は次のとおりです。

- 読み上げ速度（0.5〜1.5倍）
- 前後のチャンクへの移動
- A–B 区間リピート（今のチャンクを A、別のチャンクを B にしてくり返し。チャンクの ⟲ で1チャンクだけくり返し）
- 読み上げ中のチャンクの強調
- 英文・和訳・解説の表示を個別に切り替え（非表示の項目はタップで1つずつ表示）

ほかに、録音の保存・削除・ダウンロード、録音ファイルの取り込み、お気に入り、学習時間と完了履歴、前回の続きからの再開、テキストの編集（チャンクの分割・結合、和訳、キーワード）、バックアップと復元に対応しています。

## 使い方

1. 「作る」タブで「テキストファイルを選ぶ」（.txt / .md / .srt / .vtt）か、英文を貼り付ける
2. 必要なら和訳・タイトル・テーマ・チャンクの長さを入れる（下に自動分析の結果がプレビューされます）
3. 「この内容で作成」→ Step 1 から練習

初回から例文3本（オリジナル）で試せます。

### iPhone で使うときのヒント

- **声をよくする**：「設定」アプリ →「アクセシビリティ」→「読み上げコンテンツ」→「声」→「英語」で、拡張（高品質）の声をダウンロードできます。ダウンロード後に、このアプリの「設定」タブで声を選んでください。
- **音が出ないとき**：音量と消音（マナーモード）スイッチを確認してください。
- **録音**：イヤホンの使用をおすすめします。録音中は iPhone の仕様で読み上げの音量や出力先が変わることがあります。
- **ホーム画面に追加**：Safari の共有ボタン →「ホーム画面に追加」で、アプリのように使えます（データも消えにくくなります）。

## ローカルで動かす

リポジトリのルートで次を実行し、http://localhost:8080/echo-lines/ を開きます。

```bash
python3 -m http.server 8080   # または npx http-server -p 8080 -c-1
```

マイク録音は `https://` か `localhost` でのみ使えます。

## GitHub Pages

相対パスだけで書かれているため、Pages のサブパスでそのまま動きます。このリポジトリは Settings → Pages で「Deploy from a branch / `main` / root」に設定済みなので、`main` に入ると https://kouheim1979.github.io/study/echo-lines/ に反映されます。

## テスト

```bash
npx http-server -p 8080 -c-1     # リポジトリのルートで
BASE=http://127.0.0.1:8080/echo-lines/ node echo-lines/tests/e2e.cjs
```

Playwright（Chromium）で、テキストファイルのアップロードから自動分解、各ステップ、録音と聞き比べ、穴うめ、完了記録、再読み込み後の復元、編集、バックアップと復元までを通しで確認します。
ヘッドレス環境には音声がないため、読み上げは時間どおりにイベントを返す疑似エンジンに置き換えています。マイクは Chromium の疑似デバイスを使います。

## 注意

- 読み上げの声・音のつながりの再現度は、端末と選んだ声によって変わります。
- 音の変化の解説は、つづりから機械的に推定した目安です。実際の発音と異なる場合があります。
- 著作権のあるテキストは、個人の学習の範囲で使ってください。入力したテキストは外部に送信されず、リポジトリにも含まれません。
