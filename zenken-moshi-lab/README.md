- 2026年8月 第3回：5教科・得点、偏差値、単元別得点と配点

- 2026年10月 第5回：5教科・得点、偏差値、単元別得点と配点（各教科100点と照合済み）

## 使い方

PINでロック解除し、「単元の実力分析」で月と教科を切り替えます。8～10月の得点／配点は累計でき、7月は設問ごとの正誤として別集計しています。直近の苦手、平均との差、改善傾向、学校判定などを確認できます。

データはサイト上ではAES-GCMで暗号化し、PIN入力後にブラウザ内で復号します。認証Cookieは30日間。編集・追加データはブラウザ内に暗号化して保存します。**4桁PINは推測されやすく、厳密なサーバー側アクセス制限ではありません**。サイトのソースは公開されますが、実名や平文の成績はコミットしていません。
