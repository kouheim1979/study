# Shadowing Studio（シャドーイング・スタジオ）

ログインもAPIキーも不要で、ひとりで英語シャドーイングを進められる静的Webアプリです。
iPhone の Safari を優先して設計し、PC のブラウザでも使えます。UI は日本語です。

- 公開URL（GitHub Pages）: https://kouheim1979.github.io/study/shadowing-studio/
- 録音・自分の教材・学習履歴は **この端末の中（IndexedDB）だけ** に保存されます。外部サーバーへは送信しません。

## できること

| 機能 | 内容 |
|---|---|
| 教材を選ぶ | レベル（A1〜B1）・テーマ・キーワードで検索／絞り込み、お気に入り、並び替え。初回からすぐ使えるオリジナルサンプル4本（音声・英文・和訳・単語・チャンクの時刻がそろったもの） |
| 6ステップ練習 | ① 台本なしリスニング → ② 単語の意味と発音 → ③ チャンクごとの意味理解 → ④ リピーティング（お手本 → ポーズで発声）→ ⑤ シャドーイング → ⑥ 和訳と理解度の確認。上部のステップ番号からいつでも戻れます |
| 聞き取れない箇所の反復 | 再生速度 0.5〜1.5倍、チャンク単位の再生、A–B区間リピート（現在位置で A/B 設定・0.1秒単位の微調整・チャンクの ⟲ ボタン）、再生中チャンクの強調、英文／和訳／解説（リンキング・脱落など）の表示を個別に切り替え（非表示の項目はタップで1つずつ表示） |
| 録音と聞き比べ | お手本を再生しながらマイク録音（A–B 区間だけの録音も可）。再生中に「お手本／自分の声」を同じ位置で切り替え、チャンクごとに「お手本 → 自分」を続けて再生。録音の保存・削除・ダウンロード。マイクが使えないときは録音済みファイルを取り込み |
| 添削の受け渡し | 録音＋教材情報（英文・チャンク時刻）を「添削依頼ファイル」として書き出し → 講師はレビューモードで聞きながら、発音・音声変化・リズムなどに **時刻付きコメント** と講評・評価を付けて「添削結果ファイル」を書き出し → 学習者が取り込むと、コメント箇所を自分の声・お手本で聞き直し、「この区間を練習」でA–Bリピートに設定 |
| 自分の教材 | 手持ちの音声ファイル＋英文の貼り付けで登録（文・カンマで自動チャンク分け、和訳・単語も貼り付け可）。区間の開始・終了は「タップで区切るモード」や数値／±0.1秒で後から編集。分割・結合・削除も可能 |
| 記録 | 教材ごとの学習時間、日別の学習時間（直近14日）、ステップの進み具合、完了履歴（確認問題の点数と聞き取り自己評価の変化）、前回の続きから再開 |
| バックアップ | 学習履歴・自分の教材（音声含む）・録音・添削を1ファイルに書き出し／復元 |

## 起動方法

### GitHub Pages で使う

https://kouheim1979.github.io/study/shadowing-studio/ を開くだけです。
iPhone では Safari の共有ボタン →「ホーム画面に追加」で、アプリのように全画面で使えます（データも消えにくくなります）。

### 手元のPCで動かす

ES Modules を使っているため、`file://` ではなくローカルサーバー経由で開いてください。リポジトリのルートで:

```bash
python3 -m http.server 8080
# または: npx http-server -p 8080 -c-1
```

ブラウザで http://localhost:8080/shadowing-studio/ を開きます。
マイク録音は `https://` か `localhost` でのみ使えます（iPhone から PC のローカルサーバーへ http でアクセスした場合は録音できないので、ファイル取り込みを使ってください）。

### iPhone で使うときのヒント

- 録音時は **イヤホン推奨**。スピーカーで再生するとお手本の音が録音に入り、聞き比べにくくなります。
- 初回の録音時にマイクの許可を求められます。拒否した場合は「設定」→「Safari」→「マイク」で許可できます。
- 書き出し（録音・添削依頼・添削結果・バックアップ）は共有シートが開くので、「ファイルに保存」やメール・AirDrop を選べます。取り込みは「ファイル」アプリから選べます。

## 教材の追加方法

### アプリ内で追加する（自分の教材）

1. 「教材」タブ →「＋ 自分の教材」→「新しい教材を登録」
2. タイトル・レベル・テーマ、音声ファイル（mp3 / m4a / wav など）を選び、英文を貼り付けます
   - 分け方は「文＋カンマで分ける（おすすめ）」「1文＝1チャンク」「1行＝1チャンク」から選択
   - 和訳は文の順に1行ずつ（「1行＝1チャンク」ならチャンクの順）、単語は `単語 | 意味 | 発音メモ` の形で1行1語（任意）
3. 「登録して区間を編集する」→ 区間は文字数から仮に割り当てられるので、**タップで区切るモード**（音声を聞きながら各チャンクの終わりでボタン／PC はスペースキー）か、数値・±0.1秒ボタンで合わせて保存
4. チャンクごとの意味や、リンキング・脱落などの解説もこの画面で書き込めます

ELLLO（A2 など）や QQEnglish Basic English Book 3 など、**利用規約で個人の学習利用が認められている範囲** の手持ち教材を使ってください。
自分の教材はこの端末の中だけに保存され、リポジトリには含まれません（バックアップファイルには含まれるので取り扱いに注意してください）。

### 同梱サンプルを追加・作り直す（開発者向け）

サンプルは `tools/samples_content.py` に本文・和訳・解説・単語・確認問題を書き、`tools/build_samples.py` で音声と JSON を生成しています。
文ごとに音声合成し、合成エンジンの単語タイミングからチャンクの開始・終了を求めるので、時刻がずれません。

```bash
sudo apt-get install festival festvox-us-slt-hts ffmpeg
python3 shadowing-studio/tools/build_samples.py
```

生成物: `samples/<id>.json`、`samples/audio/<id>.mp3`（本文）、`samples/audio/<id>-words.mp3`（単語）、`samples/index.json`（一覧）。
配布の許諾がない教材をここに追加しないでください。サンプルを追加・変更したら `sw.js` の `VERSION` と `PRECACHE` も更新してください。

## GitHub Pages の設定手順

このアプリは相対パスだけで書かれているので、`https://<user>.github.io/<repo>/shadowing-studio/` のようなサブパスでそのまま動きます。

1. GitHub のリポジトリ → **Settings** → **Pages**
2. **Build and deployment** の Source で **Deploy from a branch** を選択
3. Branch に `main`、フォルダに `/ (root)` を選んで **Save**
4. 数分後、`https://<user>.github.io/<repo>/shadowing-studio/` で開けます（Actions タブの「pages build and deployment」が緑になれば完了）

この `study` リポジトリはすでに `main` / root で公開されているため、`main` にマージされれば https://kouheim1979.github.io/study/shadowing-studio/ に反映されます。
別リポジトリとして公開する場合も、このフォルダの中身をそのまま置けば動きます（ビルド不要）。

## データの保存とプライバシー

- 保存先: ブラウザの IndexedDB（教材・録音・添削・進捗）と localStorage（表示設定）。サーバーやクラウドには送りません。
- ブラウザのデータ削除、Safari の「履歴とWebサイトデータを消去」、長期間未使用（iOS の仕様）で消えることがあります。「設定」タブから定期的にバックアップしてください。
- 添削依頼ファイルには録音音声が含まれます。送る相手に注意してください。

## テスト

Playwright（Chromium・疑似マイク）で、教材選択 → 区間再生・A–B → リピーティング録音 → シャドーイング録音 → 聞き比べ → 添削依頼の書き出し → レビューモードでコメント → 添削結果の取り込み → 該当箇所の再生 → 完了記録 → 再読み込み後の履歴復元 → バックアップ／復元 → 自分の教材の登録・区間編集、までを通しで確認します。

```bash
npx http-server -p 8080 -c-1        # リポジトリのルートで
BASE=http://127.0.0.1:8080/shadowing-studio/ node shadowing-studio/tests/e2e.cjs
```

## 出典・ライセンス

- 学習手順（台本なしリスニング → 単語 → チャンク理解 → リピーティング → シャドーイング → 理解確認）は、ENGLISH COMPANY が公開している「シャドプラス」のトレーニングの流れを参考にしています。本アプリは同社とは無関係の独立したアプリで、名称・画面・教材はすべて独自に作成したものです。同サービスの教材・音声・画像は含みません。
- 同梱サンプルの英文・和訳・解説・確認問題はこのアプリのためのオリジナルです（[LICENSE-SAMPLES.md](LICENSE-SAMPLES.md)）。
- サンプル音声は CMU ARCTIC「slt」話者の HTS 音声（Festival / `festvox-us-slt-hts`、目的を問わず使用・複製・改変を認めるライセンス）による合成音声です。合成音声のため、解説にある弾音化・連結などの音声変化は完全には再現されません。解説は一般的な傾向として読んでください。
