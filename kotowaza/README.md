# ことばクエスト
## 〜慣用句・ことわざ・古事成語バトル〜

小学4年生向けに作った、ことば学習クイズゲームです。  
慣用句・ことわざ・古事成語を、暗記だけでなくゲーム感覚で楽しく学べます。

## 概要
- 1プレイ10問、約3〜5分で遊べる学習ゲーム
- スマホ・PCどちらでも遊べるレスポンシブデザイン
- ビルド不要、`index.html` を開くだけで動作
- 外部API・外部ライブラリ不使用
- localStorage で学習記録を保存

## 対象ユーザー
- 小学4年生（および保護者・先生）
- 慣用句・ことわざ・古事成語を楽しく学びたい人

## 主な機能
- 7画面構成
  - タイトル画面
  - モード選択画面
  - クイズ画面
  - 結果画面
  - 言葉図鑑画面
  - 復習画面
  - 設定画面
- 5モード
  - 慣用句
  - ことわざ
  - 古事成語
  - ミックス
  - 復習
- 3種類の問題形式をランダム出題
  - 意味を選ぶ
  - 言葉を選ぶ
  - ストーリー
- 問題データ45問（慣用句15 / ことわざ15 / 古事成語15）
- 難易度設定（かんたん / ふつう / むずかしい）
- コンボ・ボーナス・ヒント減点
- 図鑑コレクション（未取得は「？？？」）
- 間違えた問題の復習モード
- 学習記録リセット（二段階確認）

## 遊び方
1. タイトル画面で「ゲームスタート！」
2. モードを選ぶ
3. 10問のクイズに回答する
4. 結果画面で正解数・スコア・ランク（S/A/B/C）を確認
5. 図鑑で取得した言葉を確認
6. 復習モードで間違えた問題をやり直す

## GitHub Pagesで公開する方法
初心者向けに、最短手順で書いています。

1. GitHubにリポジトリを作る
2. このプロジェクトのファイルをアップロードする
3. リポジトリの **Settings** を開く
4. 左メニューの **Pages** を開く
5. **Branch** を `main` / `root` にする
6. **Save** を押す
7. 表示されたURLにアクセスする
